## 変更3：判定式（`scripts/pipeline/analyze_seeds20.py` に実装済み）

### 3.1 大失敗の定義

**T_control の median が 47 px を超えた生成**（§37.5 の関門を落ちた生成）。
T_coherence の不合格（個数 ≠ 1 が 3 本以上）は報告のみとし、大失敗には数えない。

### 3.2 精度（問い 1：失敗していないときの正確さに差があるか）

```
各ペア X, Y について
  使う seed   = X と Y の両方で大失敗していない seed
  d_s         = median_X,s − median_Y,s   （同じ seed どうしの差）
  区間        = d の平均の 98.33% ブートストラップ区間（Bonferroni 0.05/3、10,000 回、percentile 法、乱数 seed 0）
  主張する条件 = 使う seed ≥ 10  かつ  区間が 0 を含まない  かつ  |d の平均| > 1.81 px
```

- 1.81 px = max(F_det 0、F_micro 0.10、F_eval 1.81)。§15 の「Arm 間差 ≤ Evaluator floor なら主張しない」を守る
- F_train（学習のやり直しによるブレ）は含まない。A / B で測っていないため。**限界として書く**
- 「使う seed ≥ 10」は、既存の G1〜G4 で動作確認した際に、3〜4 本では区間が狭く出すぎると分かったため入れた。**G5〜G20 を見る前に決めた**

### 3.3 安定性（問い 2：大失敗の起きやすさに差があるか）

```
各ペアで、大失敗の本数（k_X / 20 と k_Y / 20）を Fisher の正確検定（両側）で比べる
主張する条件 = p < 0.05 / 3 = 0.0167
```

**検出力は低い。** 例えば 0 / 20 と 5 / 20 でも p = 0.047 で、主張できない。
0 / 20 と 7 / 20 で p = 0.0083 になり、初めて主張できる。

### 3.4 比較

Primary = B vs C、Secondary = A vs B、A vs C（§2）。新しい比較は足さない。
