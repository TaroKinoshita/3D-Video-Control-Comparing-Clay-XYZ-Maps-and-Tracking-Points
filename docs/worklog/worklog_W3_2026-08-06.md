## 2. 設計上の重要な決定（W3 で確定したもの）

| # | 決定 | 理由 |
|---|---|---|
| 1 | **§18-7 の許容値を「谷」ではなく「不感」で決めた** | 半影が連続量なので谷が存在しない。0→32 で M_invariant が 0.089% しか動かないため下端に置く。論文には感度表を robustness として載せる |
| 2 | **許容値 0（bit 完全一致）は採らない** | R1（Cycles / 512 sample）ではサンプルノイズで何も bit 一致せず、split をまたぐと mask が崩壊する |
| 3 | **Target シルエット 2px 以内を幾何的に除外**（閾値ではなく erosion） | 幾何パスは `filter_size 0.01`、tv は 1.5。AA の非対称で near 群が far の 64 倍汚れる。閾値で殺すと許容値を 135 まで上げる話になり本末転倒 |
| 4 | **mask は R0S0 で確定し全 split で共有** | M_invariant は編集の性質でありレンダラの性質ではない。split ごとに作ると測定領域が変わって横比較できない。R1 のノイズは spillover の noise floor として別に測る |
| 5 | **§11 は max、§16.8 は mean**（チャンネルの畳み込みを使い分ける） | 除外判定は「1chでも動いたら不変でない」= max。色誤差は量なので mean。混ぜると §16.11 の 11.30 / 2.29 と接続できない |
| 6 | **色誤差の判定を帯別に行い悪い方を採る** | 全240点の平均だと 168 点の背景（分離 20.898 px / 低占有率）が 72 点の Target を薄める |
| 7 | **採点スクリプトを GPU 側と分離** | 復元を `.npy` で残せば採点は無料で何度でも回せる。指標の修正で Pod を立て直さない |
| 8 | **描画を再現して armC PNG と bit 比較する検査を入れた** | 中心画素の丸め規約が描画側と採点側で同一であることを機械的に保証する。off-by-one と上下反転がここで必ず落ちる |
| 9 | **per-frame 指標は n < 5 を別扱い** | index 43 は n=2 で 1.50 と出たが速度からの期待値は 4〜5 |
| 10 | **240 点で凍結。増やさない** | VAE 側は 5.6 倍余っているが局所占有率 29.40% が拘束する。加えて点を増やすと「疎な追跡点 vs 密な Arm B」という対比が薄れる（研究上の理由でも増やさない） |
| 11 | **`.npy`（235MB）は network volume に残し、持ち帰らない** | Terminate してもボリュームは消えず、30秒で再生成できる |

## 3. 発見（論文に使えるもの）

### 3.1 色誤差は局所占有率ではなく速度でほぼ決まる

Scene C は **Target だけが動き、他 168 点は全部静止**。**1つのシーンの中に速度の
対照条件が最初から入っていた**（意図した設計ではない）。

| 区間 | 速度 | Target 帯 色誤差 |
|---|---|---|
| edited index 13–23（停止） | 0 | **2.488** |
| index 0–12（共有） | 5.0388 | 3.875 |
| original index 13–23 / 24–34 | 5.0388 | 4.570 / 4.887 |
| edited index 24–34（catch-up） | **9.3023** | **7.851** |

```
色誤差 = 0.5664 × V + 1.9682        R² = 0.896
```

**V=17 への外挿 11.60 が §16.11 の実測 11.30 と一致（差 0.30）。**
シーン・点数・占有率（12.77% → 局所 29.40%、2.3 倍差）が全部違うのに同じ直線に乗った。

これは**予測が外れたことによって得られた知見**。もともと「局所占有率 29.40% が
効くはず」と踏んで帯別採点を設計したが、占有率はほぼ効かなかった。ただし
**帯別採点自体は正解**で、それがあったから「Target 帯が悪いのは混雑ではなく速度」
と分離できた（Non-target が V=0 だったため）。

### 3.2 temporal / framewise の優劣が速度で逆転する

| 帯 | 速度 | temporal | framewise | 勝つ方 |
|---|---|---|---|---|
| Non-target | 0 | **1.494** | 2.203 | temporal（0.68 倍） |
| Target | 0〜9.30 | 4.231 | **2.890** | framewise（1.46 倍） |

§16.9 の「V=0 では時間圧縮ありのほうが良い（量子化ノイズの平均化）」という観察と、
動くと逆転する現象を**1つのシーンの中で同時に観測した。**

§16.13 の「束の3番目が最良」も再現（temporal 1.797 / 1.841）。
framewise では束内の差がほぼ消える（2.286〜2.347）ため、**この差が時間圧縮由来**
であることの裏付けになった。

### 3.3 平均だけ見ると保証ラインの破れを見落とす

`edited / temporal` の Target 帯に **色誤差 24.00 の点が存在**し、
**1,836 点中 14 点（0.76%）が最近傍を誤った**（identity 99.24%）。

24 は「最近傍が必ず正解に戻る」保証ライン（48.0833 / 2）なので、24 ちょうどで
保証が切れる。**設計どおりの挙動だが、平均 4.231 だけ報告すると見えない。**
→ §18-6 は平均ではなく分位点で決める。

### 3.4 Arm C の遮蔽区間は target video と別（7 vs 5 フレーム）

| 量 | 区間 |
|---|---|
| 完全遮蔽（target video のシルエット画素） | **36–40（5フレーム）** |
| **Arm C の情報ゼロ区間（選定 72 点の可視）** | **35–41（7フレーム）** |

可視 Target 点数：index 34 で 6、**35–41 で 0**、42–43 で 2、44 で 7、48 で 15。

**index 35–41 の7フレーム、Arm C は Target の情報をまったく持たない。**
一方 Arm B は Position パスなので、見えているシルエット画素ぶんの情報を持ち続ける。
**表現の設計に由来する非対称であり、RQ2 の解釈に直接使える。**

`render_arm_c.py` の `fully_occluded_*` は 36–40 しか検査していないため、
35 と 41 が 0 であることは今まで検出されなかった。

### 3.5 背景の identity には情報がほとんど無い

Non-target 帯の **近傍数 = 1.00**（20px 以内に他の点が1つも無い）。達成分離
20.898 px と整合。だから identity 100% は当然で、§16.3 の 6.8 近傍と比較不能。
§16.12 の警告が実データで裏付けられた。

## 5. 作法に追加したもの（どちらも「無言で壊れる」型）

| # | 作法 | 由来 |
|---|---|---|
| **23** | **`open()` には必ず `encoding="utf-8"` を書く** | Python 3.11+ の既定はロケール依存。Windows（cp932）で `UnicodeDecodeError`、さらに cp932 で解釈できる範囲なら**無言で別の文字として読める**。子プロセスの stdout も `PYTHONIOENCODING=utf-8` で固定 |
| **24** | **PowerShell の `Compress-Archive` を使わない** | パス区切りがバックスラッシュになり、Linux で `edited\armC_0000.png` という1個のファイル名になる。**zip の md5 は一致するので転送検証では検出できない。** 代わりに `python -c "import shutil;shutil.make_archive(...)"` |

W1/W2 の既存スクリプトも #23 の穴を持つ（`json.load(open(...))` に encoding 指定なし）。
**RunPod では utf-8 が既定なので今まで露見しなかった。** 次に触るときに直す。

## 11. 引継ぎ時に守ってほしいこと（W2 から継続）

- **API を推測しない。プローブで実測する**（W2a 1/7、W2b Step1 0/3、W3 の RunPod 0/2）
- **enum の内省を信用しない。直接代入して確かめる**（作法 #16）

「エラーも警告も出さずに間違った出力を出す」経路は W2 で3つ、W3 で2つ見つかった。
**共通するのは出力がもっともらしく見えること。**
