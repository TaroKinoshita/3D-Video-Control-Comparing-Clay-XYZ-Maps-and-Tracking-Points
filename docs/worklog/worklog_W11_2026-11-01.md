## 2. 予測の答え合わせ（§43.5）

| # | 予測 | 結果 | 判定 |
|---|---|---|---|
| Q1 | spill_mae は 0.5〜6 | **0.27〜0.44** | ❌（予測より 1 桁近く小さい） |
| Q2 | outside_mae は 0.3 以上 | 0.32〜0.59 | ✅ |
| Q3 | C が最大、A と B は近い | C 0.357 / B 0.298 / A 0.284 | ✅ |
| Q4 | 編集の実現度：A / B ≤ 8、C ≤ 12 | A 3.5〜3.8 / B 2.6〜3.0 / C 2.4〜5.4 | ✅ |

**Q1 を外した理由**：背景が静止しているシーンでは、control が変わっても背景の生成はほぼ同じ画素に収束すると考えていなかった。
p95 = 1 なので、漏れの大半は 8bit の ±1 の揺れである。

**Q5 を外した理由**：差の向きは当たった（C が最大）。だが Arm C の seed による揺れ（0.297〜0.441）が、arm 間の差（最大 0.07）より大きかった。

## 3. 探索的な観察（事前登録外。主張には使わない）

- PSNR は A 52 dB / B 43〜49 dB / C 41〜49 dB で、平均（MAE）より arm の違いが見えやすい。PSNR は大きい差に敏感なので、まれな大きな漏れが C に多い可能性がある。**PSNR は報告のみと決めたので、判定には使わない**
- outside_mae（GT が一致する区間の全画面差）も A 0.32〜0.41 / B 0.39〜0.44 / C 0.47〜0.59 と同じ順。時間方向の漏れ（9 月の Temporal spillover）の予備観察として記録する
