## 1. 未決 #29：「Target の個数 ≠ 1」は生成の破綻か、採点器の限界か → **ほぼ全部が採点器の限界**

手元にある生成動画 28 本（Phase 0.8 の G1 × 3、Arm C G4、RQ2 の 24 本）で、GT 可視フレームのうち
オレンジ成分（Marker 近傍を除く）が 2 個以上あるフレームを調べた。`data/reports/w13_issue29_components.txt`。

| 2 番目に大きい成分 | フレーム数 | 出どころ |
|---|---|---|
| **≤ 56 px（かけら）** | **40** | 遮蔽板の縁で Target の細い帯が色判定で分かれたもの。index 41（11）/ 34（7）に集中 |
| 200〜999 px（どちらとも言えない） | 3 | すべて Arm C G4 |
| **≥ 1,000 px（複製）** | **33** | **すべて Arm C G4**（Target の複製） |

- 同じフレームで、GT マスクは 1 成分、正解動画に tracker を当てても 1 成分
- **結論：Arm C G4 を除けば、T_coherence の不合格は生成の破綻ではなく、色セグメンテーションが細い帯を分断する採点器の限界**
- 規則は事後に変えない。サイズ閾値つきの coherence 規則は拡張の優先順位 3 として論文 §6.2 に入れた
- 限界：seed 追加分（G5〜G20）と学習曲線の動画は Volume にあり、ここでは調べていない
