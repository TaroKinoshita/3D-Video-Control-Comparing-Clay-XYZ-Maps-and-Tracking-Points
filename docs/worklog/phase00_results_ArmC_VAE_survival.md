# Phase 0.0 結果 — Arm C 制御表現の VAE 生存性

卒論 Results 用の数表と本文素材。2026-08-02 時点。
測定スクリプト: `make_dots_video.py` / `vae_roundtrip_video.py` /
`score_video.py` / `score_delta.py`

---

## 0. 目的

Arm C（Object-Aware 3D Tracking）は疎な点で3D対応を表現する。
点は Wan2.1-VACE の VAE を通って潜在に落ちるため、
**点の同一性が圧縮を生き延びるか**が表現として成立する前提条件になる。

ラウンド1-2（静止画）で空間圧縮（8×8）は通過済み。
本節は**時間圧縮（4フレーム → 潜在1枚）**への耐性を扱う。

---

## 1. 測定条件

| 項目 | 値 |
|---|---|
| モデル | Wan2.1-VACE-1.3B の VAE（`Wan2.1_VAE.pth`） |
| 解像度 / フレーム数 | 832 × 480 / 49（`1 + 12×4`） |
| 潜在形状 | `[1, 16, 13, 60, 104]` |
| 精度 | bfloat16 |
| tiling | 無効 |
| 点の色 | 局所最大分離パレット12色（最小色間距離 48.1） |
| 分離割当半径 | 24 px |
| 運動モデル | ラップアラウンド一様並進、方向 2:1（約26.6°） |
| 端の除外帯 | 110 px（全速度共通） |
| アンチエイリアス | なし |

### 指標

| 指標 | 定義 | 性質 |
|---|---|---|
| **色誤差** | 正解位置における復元色と正解色の8bit平均絶対誤差 | 点密度に非依存。**主指標** |
| 最良色誤差 | 正解位置の周囲20px以内で最も正解色に近い画素の誤差 | 同上 |
| identity復元率 | 復元色を近傍20px以内の点の正解色と照合し、最近傍が自分自身である割合 | **点密度に依存。補助指標** |
| Entity精度 | Target / Non-target / 空 の3値分類精度 | |
| ズレ量 | 正解色に最も近い画素までの距離 | 点の縁までの距離。**半径ごとに床が異なる** |

判定基準は色誤差 ≤ 24（局所最小色間距離 48.1 の半分）。

**採点母数** 描画の重なりで中心画素が他点に上書きされた点は除外する
（VAEに入る前から復元不能なため）。半径3・1872点で約7%。

---

## 2. 結果1 — 劣化の原因は時間圧縮である

半径3px・1872点。同一の入力映像を2通りで符号化した。

| V (px/frame) | 時間圧縮あり | 時間圧縮なし（framewise） |
|---:|---:|---:|
| 0 | 93.5% | 92.0% |
| 5 | 87.5% | 92.6% |
| 10 | 60.2% | 92.7% |
| 17 | 49.3% | 92.5% |
| 25 | 52.4% | 92.6% |
| 34 | 53.0% | 92.4% |

（identity復元率。半径3・1872点・平均近傍数6.8）

**時間圧縮なしでは V=34 でも一切劣化しない。**
運動そのものは無害であり、劣化は4フレームを潜在1枚に束ねる操作に起因する。

補足として、V=0 では時間圧縮ありのほうが良い（93.5% > 92.0%）。
静止した4フレームを束ねると量子化ノイズが平均化されるため。

---

## 3. 結果2 — 劣化は位置ズレではなく色の希薄化である

束の中の位置ごとに identity が系統的に異なる（下表）ことから、
「VAE は束を代表時刻1つとして再構成しており、点は時刻を取り違えているだけ」
という仮説を立て、復元フレーム t を正解フレーム t+δ で照合した。

| V | δ=−2 | δ=−1 | **δ=0** | δ=+1 | δ=+2 |
|---:|---:|---:|---:|---:|---:|
| 5 | 15.7% | 16.4% | **87.3%** | 16.3% | 16.8% |
| 10 | 17.3% | 17.2% | **59.4%** | 18.2% | 16.9% |
| 17 | 17.5% | 18.2% | **48.4%** | 17.6% | 17.7% |
| 34 | 17.9% | 17.9% | **52.0%** | 18.0% | 17.8% |

全速度・全束位置で最良は δ=0。δ≠0 は偶然の一致率（1/6.8 ≒ 14.7%）と同水準。
**点は正しい位置にあり、経路上に伸びた足跡も生じていない。**
失われているのは位置ではなく色である。

（検出器は、各束の4フレームすべてに束の3番目の内容を入れた
合成データで階段 +2/+1/0/−1 を100%検出できることを事前に確認済み。）

## 4. 結果3 — 束の中の位置による系統差

潜在チャンク内の位置別 identity（半径3・1872点）。

| V | frame 0 | 束1番目 | 2番目 | **3番目** | 4番目 |
|---:|---:|---:|---:|---:|---:|
| 0 | 92.0% | 93.5% | 93.8% | 93.3% | 93.5% |
| 5 | 92.0% | 81.0% | 87.4% | **91.5%** | 89.9% |
| 10 | 92.0% | 45.7% | 60.1% | **67.7%** | 64.5% |
| 17 | 92.0% | 45.6% | 40.7% | **60.3%** | 47.1% |
| 34 | 92.0% | 47.9% | 44.2% | **65.1%** | 51.7% |

**束の3番目が常に最良**という規則は、半径6・半径9・半径3(480点) を含む
全4構成・全速度で再現した。機序は未特定。事実として記録する。

frame 0 は単独で潜在1枚を持つため（causal VAE の構造）、
速度によらず 92.0% 前後で一定。静止画テスト（ラウンド2で91.8%）との
接続点になっており、測定パイプラインの妥当性検証にも用いた。

## 6. 結果5 — identity は点密度に汚染される

半径3・1872点 と 半径3・480点 は**半径も速度も同一で、点数だけが違う。**

| V=17 | 1872点 | 480点 | 差 |
|---|---:|---:|---:|
| identity | 49.3% | 85.7% | +36.4 |
| 色誤差 | 29.77 | 23.73 | −6.0 |

identity が36ポイント動くのは、近傍の紛らわしい相手が減ったためであり、
点の品質は変わっていない。一方、半径3・480点 と 半径6・480点 は
点数・近傍構造が同一で半径だけが違い、色誤差が半減する（23.73 → 11.30）。

```
identity = 点の品質 × 近傍の紛らわしさ
色誤差   = 点の品質
```

Arm A / B / C は表現の密度が本質的に異なるため、
**Arm間の横比較には色誤差を用いる。**

---

## 7. 結論

1. Arm C の点表現は、VAE の時間方向4:1圧縮によって色が希薄化する。
   運動そのものは無害であり、劣化は圧縮に起因する。
2. 劣化は位置の誤りではなく色の希薄化であり、
   時間方向の補償では回復しない。
3. 点半径を 3px → 6px にすると、V=17 px/frame でも色誤差は
   判定基準の半分以下に収まる。**半径6を採用する。**
4. identity復元率は点密度に依存するため、Arm間比較の主指標に
   用いてはならない。色誤差を用いる。

---

## 8. 限界

1. **往復テストは代理指標である。** LoRA が消費するのは潜在であり、
   復元画素ではない。デコーダで復元できない情報が潜在に
   まったく無いとは限らない。保守的な設計指標として扱う。
2. **運動モデルは一様並進で、視差がない。** 実シーンではカメラ運動により
   手前と奥で速度が異なる。得られた V_max は楽観側の値である。
3. **V_max の上限は未測定。** 半径6で17を超える速度は試していない。
   「V_max ≥ 17」は下限の主張である。
4. **半径9の標本が小さい。** 採点対象が毎フレーム73〜87点で、
   誤差は約±3.5ポイント。傾向の確認には足りるが、
   細かい値の比較には使えない。
5. **GPU間で約0.3ポイントの差が出る。** bf16 演算のハードウェア差。
   これ以下の差は有意と見なさない。
6. **ズレ量は半径をまたいで比較できない。** 点が大きいほど
   同色画素が広範囲に存在するため、指標の床が半径とともに上がる。
7. **半径6での点数上限は未測定。** 本節の測定は全画面480点でのみ行った。
