## 0. 結論

**精度（失敗していないときの正確さ）では、B vs C と A vs C で「表現による差あり」と主張できる。** どちらも Arm C が悪い。
A vs B は区間こそ 0 を含まないが、差（1.00 px）が採点器の床（1.81 px）に届かず、主張しない。
**安定性（大失敗の起きやすさ）では、どのペアも主張できない。**

| 問い | ペア | 平均の差（px） | 98.33% 区間 | 判定 |
|---|---|---|---|---|
| 精度 | **B vs C**（Primary） | −2.56 | [−3.54, −1.56] | **主張可（B が良い）** |
| 精度 | A vs B | −1.00 | [−1.27, −0.73] | 主張不可（床 1.81 未満） |
| 精度 | A vs C | −3.58 | [−4.48, −2.73] | **主張可（A が良い）** |
| 安定性 | B vs C / A vs B / A vs C | 失敗 0 / 0 / 1（C） | Fisher p = 1.0 | 主張不可 |

§42.5（G1〜G4、混ざった平均での判定 → 3 ペアとも主張不可）は**置き換えない**。論文では「事前登録した追加実験」として並べて書く。

## 4. 限界（論文に書く）

1. **学習のやり直しによるブレ（F_train）は Arm C でしか測っていない**（1.79 px）。A / B の学習ブレは未測定。C の値を当てはめても床は 1.81 px のままで判定は変わらないが、A / B の学習ブレが大きい可能性は残る
